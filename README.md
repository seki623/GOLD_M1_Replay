# GOLD M1 Replay v0.5

開始直後のローソク足巨大化を修正。

- 表示本数を100本分で固定
- リプレイ開始前の過去M1を最大100本ウォームアップ表示
- ウォームアップ足は再生対象外
- 現在足を右端側へ固定
- 新しい足が増えると左側の古い足を押し出す
- 期間指定、速度、デモトレード、マーキングを維持

CSVはMT5の元形式を使用。

```text
2025.01.02,08:00,2634.02,2634.02,2633.22,2633.41,184
```

GitHub Pagesではリポジトリ直下に `index.html`, `style.css`, `app.js`, `data/` を配置する。
