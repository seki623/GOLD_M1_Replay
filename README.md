# GOLD M1 Replay v0.4

GitHub Pages用の静的版です。Python/uvicorn不要。

## データ配置
`data/2025-01.csv` のように月別CSVを配置してください。

CSVはMT5元形式のまま使用します。
`2025.01.02,08:00,2634.02,2634.02,2633.22,2633.41,184`

## 機能
- 期間指定
- 月別CSV読み込み
- 再生速度 1〜100倍
- 1本進む/戻す
- ローソク足表示切替
- D/W/M表示の土台
- デモBUY/SELL/決済
- トレード履歴
- マーキング追加/削除/全削除
- 左上トレードパネル
- スマホ対応

GitHub Pagesで公開すればスマホから同じURLで利用できます。
