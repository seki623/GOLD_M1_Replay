# GOLD M1 Replay v0.6

v0.6では、開始直後の巨大なローソク足を「固定100本枠＋未生成領域」で解決。

- 実データが1本でも横幅は100本分を確保
- 未生成領域は価格データを持たない空白
- 実データ1本目の左側にREPLAY STARTの縦点線
- M1が1本進むたびに未生成領域が1本分減る
- 100本に達したら通常の100本表示
- 価格スケールは実データだけから計算
- CSVの日時はブローカー時刻としてUTC内部表現に固定し、ブラウザのローカルタイムゾーン変換を避ける
- 指定開始日時以降で最初に存在するM1をリプレイ1本目とする

CSV例:
2025.01.02,08:00,2634.02,2634.02,2633.22,2633.41,184

GitHub Pages: Settings → Pages → Deploy from branch → main / root
