# GOLD M1 Replay v0.7

開始直後の1本だけ巨大になる問題を、固定100本の「透明ダミー足」で解決した版。

- 常に100本分の横方向レイアウトを確保
- 実データが1本なら、残り99本を内部的なダミーOHLCで補う
- ダミー足は描画しないため背景と同じに見える
- ダミーは価格スケール、D/W/M OHLC、EMA、売買、マーキングに一切使用しない
- 実データが1本増えるたびに左端のダミー枠が1本減る
- 実データ1本目の左側にREPLAY START縦点線
- 実データが100本に達したら全枠が実データになる

CSVは `data/YYYY-MM.csv` に配置。
